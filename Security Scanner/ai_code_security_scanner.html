Issue: Command Injection

File: app.py Line: 11 Severity: Critical

Description

User input is executed directly in a shell command. This allows malicious users to append commands and execute arbitrary code on the underlying host operating system.

Vulnerable Code 

result = subprocess.check_output(cmd, shell=True)

Fix Suggestion

Avoid using shell=True. Pass command arguments as a list or sanitize input strictly using shlex.split().

Secure Code Example 

import shlex
# Safe execution without shell=True
args = shlex.split(cmd)
result = subprocess.check_output(args, shell=False)
